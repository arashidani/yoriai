# YORIAI（よりあい）

YORIAI（よりあい）は、株式会社IBJ向けの社内交流・質問共有プラットフォームである。社員同士の「はじめまして」を身近にし、部署の壁を越えたコミュニケーションを生み出すことを目的とする。

運営は「れあかつ」（IBJ 2026年度ハッカソンAチーム）が担う。

## コンセプト・テーマ

- **コンセプト:** 会社の「はじめまして」をもっと身近にする、社内特化型コミュニケーションプラットフォーム。
- **テーマ:** 「IT×おせっかい」。自らアクションを起こすのが苦手な社員に対し、システム（AI）がおせっかいを焼き、部署の壁を越えたコミュニケーションを自然に生み出す。

## 画面と機能の一覧

YORIAI の主要機能は「なんでもQ&A」と「ひろば」の2つである。サイドバーのナビゲーションからそれぞれにアクセスできる。

| 機能 | パス | 説明 |
|------|------|------|
| なんでもQ&A | `/` | 社内の疑問を投稿・閲覧・回答する知恵袋 |
| ひろば | `/hiroba` | 趣味やMBTIなどでつながるコミュニティ |
| マイページ | `/mypage` | プロフィールの確認・編集 |
| 通知 | サイドバー | 回答・いいね・メンションなどの通知 |
| 投稿・保存した質問 | `/my-questions` | 自分の質問と保存した質問の一覧 |
| よりあいぬの小屋 | 画面右下 | 公式キャラクター「よりあいぬ」と会話できるAIチャット |
